# MemeDiff brand assets

`memediff-logo.jpg` is the unmodified 512×512 official project-token image already preserved in the local launch audit. Original source: `https://ipfs.io/ipfs/bafkreia3y7m54xgpiflkoku7xcfryijq2zufpheok5pedyxu3qg3sijgii`, recorded in `docs/launch-evidence.json`. The source file had a `.png` filename but JPEG content; this copy uses its actual format. No character, text or token metadata was regenerated or changed.

The header, hero and token card reuse this same 62,327-byte asset. `favicon.png` is a 64×64 resize. `social-preview.png` is a 1200×630 layout combining the unchanged logo with the site headline; social metadata links to it. It is not downloaded as part of the normal homepage layout. The historical `favicon.svg` is retained for existing links.

Palette: near-black `#080a0b`, lime `#a8ff32`, cyan `#31e7df`, coral `#ff7068`. Coral marks the decorative “− hype” diff; it is not a market indicator. All imagery is self-hosted. Explicit image dimensions reserve layout space, the hero receives high fetch priority, and the below-fold token logo is lazy-loaded. No external font, animation library, wallet connection or tracking is introduced. Reduced-motion preferences disable smooth scrolling.
