        숫자를 읽기 전에

        01 / SCOPE

        관측한 범위만 말합니다

        조회 시각 기준 최근 7일·30일의 기본 브랜치 커밋과 공개 릴리스입니다. 커밋 최대 1,000개, 릴리스 최대 500개를 조회하며 한도·오류로 불완전하면 표시합니다. 커밋 날짜는 작성자가 변경할 수 있습니다.

        02 / CONTEXT

        활동은 신뢰도 점수가 아닙니다

        커밋 수는 코드 품질·프로젝트 독창성·토큰 안전성을 증명하지 않습니다. Fork·봇·자동 생성 코드도 활동에 포함될 수 있습니다. 가격 예측과 투자 권유를 제공하지 않습니다.

        03 / PRIVACY

        브라우저에서 직접 조회합니다

        GitHub API에 저장소 경로와 접속 IP가 전달됩니다. 토큰 주소는 GitHub에 전송하지 않습니다. 분석 서버·추적기·API 키 입력이 없으며 저장 버튼을 누를 때만 이 기기에 비교 기준을 남깁니다. 내보낸 파일에는 입력한 토큰 주소가 포함됩니다.

        비인증 GitHub API는 일반적으로 IP당 시간당 60회 요청 제한이 있습니다. 한 번의 분석에 여러 요청이 사용됩니다. 모든 날짜는 조회 시각을 기준으로 계산되며 차트는 UTC입니다.
