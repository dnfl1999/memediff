Quick start — share a Development Receipt

MemeDiff is a free, open-source tool for inspecting public GitHub development activity. No wallet, token ownership or login is required.

  1. Paste a Solana token CA and select Analyze Token. Available market data appears even without a GitHub link. A fresh, exact official Forks association starts GitHub analysis automatically.
  2. For a linked repository, choose 7 days or 30 days. Review collection warnings and source links.
  3. Select PNG Receipt for an English shareable card with the observed time, UTC window and source evidence. Export JSON too for all evidence URLs and collection errors. Image links are printed text, not clickable.
  4. Use Save baseline to save a baseline on this device. Analyze again to compare 30-day SHA observations; the comparison remains 30-day even on a 7-day card.

Advanced Search retains direct GitHub URL analysis and repository-name search. Forks associations use a limited dated index; omission is not evidence of no relationship. Counts are observations, not proof of work, quality or token safety. A + means incomplete collection. Receipts are locally generated and editable, not signed certificates. After a live analysis, select Import Previous Report to preview and compare a previous JSON export locally. Saving the imported baseline is a separate, explicit choice. There is no hosted report or automatic social posting.

          Before you interpret the numbers

          01 / SCOPE

          Observations within a defined scope

          We observe default-branch commits and public releases within rolling 7-day and 30-day windows. Collection is capped at 1,000 commits and 500 releases. Limits and errors are labeled as incomplete collection. Commit timestamps can be changed by authors.

          02 / CONTEXT

          Activity is not a trust score

          Commit counts do not prove code quality, project originality or token safety. Forks, bots and generated code may contribute to activity. MemeDiff does not provide price predictions or investment recommendations.

          03 / PRIVACY

          Queried directly from your browser

          DexScreener receives the queried CA and your IP address. GitHub receives the repository path and your IP address; token addresses are not sent to GitHub. Forks associations are read from this site’s dated index. There is no analysis server, tracker or API-key input. A baseline is stored on this device only when you choose to save it. Exports include any token address you entered.

          Unauthenticated GitHub API access typically allows 60 requests per hour per IP. Each analysis uses multiple requests. Windows are calculated from the observation time. Dates use UTC; numbers use English (US) formatting.
