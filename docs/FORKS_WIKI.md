검색 캐시와 GitHub README의 과거 수수료 설명은 현재 배포된 가이드/설정과 달랐습니다. 현재 자료를 우선합니다. 모든 수치는 변경될 수 있습니다.

현재 가이드는 공개 저장소, 지급 가능한 실제 GitHub 사람 계정, 저장소당 1개 코인, 지갑당 일 3개 런칭을 설명합니다. FORK/WIKI 계열 사칭 이름이나 공식 저장소 유사 프로젝트는 제한됩니다. MemeDiff는 빈 폴더에서 새로 구현한 독립 저장소입니다. 브라우저 UI 자동화는 URL 확인 오류로 중단되어 실제 화면의 최종 검증은 미완료입니다.

**저장소 인식 확인 완료:** 공개 게시 후 [읽기 전용 launch plan API](https://forks.wiki/api/launch/plan?repo=dnfl1999%2Fmemediff)가 HTTP 200, `ok: true`, `plan.repo: dnfl1999/memediff`, `owner.login: dnfl1999`, `owner.type: User`를 반환했습니다. 수취인 배분은 dnfl1999 3,000bps, 런처 5,000bps, Forks 2,000bps였습니다. 현재 사전검사상 런칭 대상이며 실제 발행 성공을 보장하지는 않습니다. 반환되는 일회성 ticket은 기록·공개하지 않았고 거래 build/submit API를 호출하지 않았습니다.

## 비용 및 배분

- 현재 Jito tip 설정: **0.0005 SOL**.
- 총비용: pump.fun 계정 rent + 아직 없는 GitHub 수수료 계정 생성 rent + 네트워크/우선순위 수수료 + Jito tip + 선택적 초기 매수액 및 해당 거래 수수료.
- 정확한 총액은 지갑·수취인 계정 상태와 실제 build 결과에 따라 달라집니다. 0.0005 SOL은 총비용이 아닙니다. 서명 전 견적을 확인해야 하며 이 조사에서는 거래 build/서명/제출을 실행하지 않았습니다.
- 현재 사이트 거래/초기 매수 추가 수수료 설정은 **0.5%**. pump.fun 등 기반 프로토콜의 수수료는 별도이며 클라이언트의 대략적 계산을 확정 견적으로 취급하면 안 됩니다.
- 창작자 수수료의 현재 기본 배분: 런처 지갑 50%, 저장소 측 30%, Forks 20%. 총 매매금액의 이 비율을 받는다는 뜻이 아닙니다. 저장소 측 몫에서 일부를 적격 fork 소유자에게 배분할 수 있으며 원 소유자는 최소 10%를 유지합니다. 배분은 온체인에서 고정됩니다.

## 사용자 보상

2026-11-11 읽기 전용 시즌 API: Season 0 open=true, launch 1,000 FORK, 초기 매수 0.2 SOL 이상이면 launchDevReward 1,500 FORK, 계정 최소 나이 30일, 하루 3회, 코인당 최대 1,000,000 FORK. minDevBuySol=0으로 응답해 매수 없이도 기본 보상 대상이라는 현재 규칙을 확인했습니다. 추가 보상은 시가총액/마이그레이션 조건과 재확인 절차에 따릅니다. 풀·시즌 조건이 있고 지급 대기 배정이므로 현금 수익이나 실제 지급을 보장하지 않습니다. 보상 계정 연결에는 X 로그인 및 지갑 소유 증명이 필요할 수 있습니다.
